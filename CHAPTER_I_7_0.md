# Глава I — «Тени Кривой Сосны», этап 7.0

Основа: `main / 6781b26`, после объединённого PR #34. Ветка: `codex/stage70-shadows-chapter`.
Движок проверки: **Godot 4.6.3**, Linux, Compatibility / Mesa llvmpipe.

## Запуск и управление

Открыть `HutorReborn/project.godot` и нажать **F5**. В главном меню:

- **Начать путь** — новая первая глава, Ганс на южной дороге в 17:20, шесть дорожных монет.
- **Продолжить главу** — ручное обычное сохранение.
- **Контрольное сохранение** — точка перед финальным решением/событием.
- **Тест главы I** — отдельный тестовый прогресс и выбор начала одного из шести заданий либо финала.
- **Испытание боем** — прежняя независимая арена 6.1, её сценарии и правила сохранены.

WASD/стрелки — идти; **E** — взаимодействовать; **J** — журнал; **I** — сумка;
**F5** в запущенной игре — ручное сохранение, **F9** — загрузка текущего обычного/тестового слота;
Esc — закрыть журнал/сумку или открыть прежнюю паузу. В диалоге E раскрывает/продолжает текст,
ответы выбираются мышью либо стрелками и Enter. F3 сохраняет существующее управление эффектами.

Горячие клавиши J/I свободны в исходной раскладке. Подсказка новых клавиш постоянно видна в мире.
Сохранение недоступно во время разговора, перехода, сражения и сюжетной последовательности.
Из прежней паузы сначала нужно вернуться в игру; кнопки сохранения также есть в журнале/сумке.

F6 исходной деревни остаётся просмотром старой сцены без начала сюжета. Для главы использовать главное меню.

## Игровое содержание

Южная дорога предлагает реальный самостоятельный исход «уйти», с контрольным сохранением до решения. |
| Пропавший Мирон | Четыре отдельных свидетеля, инструменты, северные следы и физический подбор топора в смоле. Порядок свидетельств/находок свободный. Топор можно отдать старосте, показать брату травницы или оставить через осмотр в сумке. Меняются владение предметом, доверие, реплики и дополнительные сведения; путь к травнице остаётся доступным. |
| Горькие корни | Травница описывает два растения. Игрок осматривает отдельные заросли и собирает валериану/чабрец. Похожий болиголов можно ошибочно взять, затем выбросить самостоятельно или с помощью травницы. Правильные ингредиенты действительно расходуются; награды — корень, две настойки, доверие и сведения. |
| Три удара | Разговор со стариком и осмотр знака на сосне. Вечером для этой встречи используется тот же старик у сосны; затем он идёт домой по существующей навигации. Доверие открывает рассказ о прошлом. Архив старосты даёт дополнительный источник сведений и не требует максимальных отношений. |
| По ту сторону тропы | Настоящая отдельная лесная сцена: колея, телега, навес, пни, корни, овраг, старое кострище и завал. Два волка охраняют колею. Есть бой, физический западный обход, расход приманки с уходом животных и возвращение в деревню. Для завершения осматриваются четыре разные находки. |
| Дом без хозяина | До открытия по сюжету дверь закрыта. После расследования выбирается одиночный поход, помощь травницы или сообщение старосте. Ночью засов открывается через ставню. Существующая травница реально входит и следует за Гансом; староста вместо свободного доступа выдаёт отдельную выписку. В доме нужны осмотр половицы, ключ и запертый шкаф; дневник остаётся в сумке. У сосны — три удара, свежие зарубки, реплика из леса и краткое появление фигуры. Затем экран завершения и возможность свободно исследовать мир/загрузить контрольную точку. |

| Побочное задание | Реальная цепочка |
|---|---|
| Сломанная игрушка | Поговорить с мальчиком → подобрать колесо у колодца → починить игрушку на верстаке общего склада → вернуть. Открывается ночное свидетельство, растёт доверие. |
| Дрова к зиме | Взять поручение жены дровосека → забрать две связки во дворе → отнести к домашней печи → отчитаться. Две монеты, доверие и сведения о муже. |
| Последняя кружка | Поручение трактирщика → осмотр/подбор кружки → опознание братом травницы → возвращение хозяину. Сведения о Мироне, монеты и приманка. |
| Сухие травы | Поручение травницы → связки на складе → сортировка на её столе → отчёт. Настойка, доверие и дополнительная улика о смоле. |

Побочные цепочки не являются условиями завершения основных заданий. Ремонт игрушки — одно квестовое действие,
а не отдельная система крафта. Нет уровней, опыта, постоянного отряда или главы II.

## Журнал, предметы, диалоги, живые события

Журнал имеет основные, побочные, завершённые задания и улики; дополнительная вкладка показывает, где сейчас жители.
У записей есть описание, текущая цель, выполненные шаги, найденные связанные улики и статус.
Будущие основные задания не раскрываются. Завершённые поручения и награды повторно не выдаются.

Сумка различает улики, квестовые предметы, материалы и расходники. У каждого предмета есть название,
описание и иконка из существующих ресурсов. Осмотр топора позволяет решить оставить его; настойку можно выпить,
болиголов — выбросить. Предметы не привязаны к экземпляру комнаты и переживают переходы/сохранение.

Используется **тот же DialogueManager и тот же диалоговый интерфейс**, исходные портреты/эмоции и блокировка управления.
Сюжетные варианты строятся по текущим уликам, предыдущим решениям и скрытому доверию. Чисел отношений в UI нет.
Во всех разговорах есть выход и вариант **«Поговорить о повседневном»**: прежние разговоры не удалены.

Староста действительно ненадолго появляется в трактире во время вечернего разговора с хозяйкой; она умолкает,
он уходит через дверь и продолжает обычную симуляцию. Дровосек может задержаться у северной тропы.
Мальчик делится наблюдениями, травница узнаёт необычные растения, старик реагирует на улики.
Ночью после первого события возле пустого дома горит свет, но сам вход до нужной стадии не открывается.

Все сюжетные появления используют **те же экземпляры жителей**. Короткое сюжетное занятие временно резервирует
нужного человека; профили расписаний не меняются. Дровосек и старик после видимой встречи идут к своей
следующей цели, а не исчезают перед игроком. Травница сопровождает только внутри сюжетного дома и возвращается
к существующей симуляции после выхода. Девять идентичностей сохраняются при переходах.

## Новые сцены и сохранение существующего мира

- `scenes/chapter/logging_camp.tscn` — редактируемая карта 1216 × 1152 с TileMapLayer, отдельными объектами,
  коллизиями, лесом, обходом, волками, туманом и звуковым фоном.
- `scenes/chapter/abandoned.tscn` — полноценный компактный интерьер: пол, стены/заколоченные окна,
  старая кровать, стол, полки/шкаф, вещи семьи, свеча/свет, тайник, вход, выход, место для травницы и коллизии.
- `scenes/chapter/ForestEncounter.tscn` — адаптер наследует представление арены и использует её неизменённое ядро.
  HP и настойки берутся из главы. Победа прогоняет волков; отступление сохраняет опасность; при поражении
  Ганс оказывается у края тропы с 54 HP и теряет до двух монет. Можно вернуться и выбрать другой путь.

Вся графика локаций, иконки, звук ударов/ветра взяты из уже существующих ресурсов. Оригинальные изображения,
шесть интерьеров, семь зданий, покрытие земли деревни, масштабы Ганса и утверждённые модели NPC не заменены.
Новые карты не используют картинку референса как фон. Генератор `tools/build_chapter_locations_70.gd` сохраняет
настоящие узлы в `.tscn`; это не пустые сцены с информационной карточкой.

Из старых файлов затронуты только пять:

1. `project.godot` — один autoload `ChapterI`.
2. `scripts/menu/main_menu.gd` — новая игра главы, загрузка и отдельный тестовый режим.
3. `scripts/world.gd` — распознавание двух сюжетных типов взаимодействия.
4. `scripts/npc/npc_interaction.gd` — сюжетные темы при активной главе, прежний путь сохраняется.
5. `scripts/life/village_life.gd` — два исключения для временно занятых сюжетом жителей.

В `scripts/chapter/` разделены состояние/правила, последствия действий, контент, мировые точки,
журнал/сумка, сохранение, окружение, боевой адаптер и координатор сессии. Боевые и диалоговые ядра не изменены.

## Сохранения и режим тестирования

Слоты: `user://chapter_i/normal/` и `user://chapter_i/test/`, в каждом `manual.save` и `checkpoint.save`.
Сохраняются флаги/этапы, завершения, инвентарь, улики, решения, отношения, события, монеты/HP,
локация/позиция/направление Ганса, игровое время и данные девяти жителей: расположение, занятие,
индекс/продолжительность текущего шага, переходы и локальный RNG. Открытие дома и финал — одноразовые флаги.

Файл имеет версию, заголовок и SHA-256. Декодируются только данные без объектов; повреждённая загрузка
отклоняется до очистки живой игры. Запись идёт через временный файл с сохранением предыдущей копии `.bak`.
Контрольная точка создаётся **до** финального события либо ухода по южной дороге. После завершения можно
сохранить игру: загрузка такого слота не запускает финал повторно. Тестовая арена не использует эти слоты.

«Тест главы I» готовит корректные прошлые флаги, улики, предметы и необходимые решения, затем открывает
выбранный этап. Пункт финала даёт дневник и помещает Ганса у сосны ночью. Сброс удаляет только тестовые слоты.
Обычное сохранение при тестовых прыжках не перезаписывается, в том числе при F5/F9.

**Это разные уровни проверки.** Полный сюжетный интеграционный прогон автоматически перемещает Ганса
к проверяемым точкам, устанавливает время для встречи с жителями и выбирает ответы существующего интерфейса.
Новые предметные точки также проверяются настоящим сенсором/синтетическим событием E.
Правила проверяют 18 комбинаций решений с двумя порядками свидетельств; это не заявление о ручном переборе
всех возможных маршрутов. Результаты боевого адаптера дополнительно проверяются явными диагностическими исходами.

Графическая запись тоже диагностическая: есть перемещения, установка времени, подготовленные состояния
и краткая обзорная камера. **Полное прохождение всей главы вручную без фикстур не заявляется.**
Нативный прогон запускает обычную игру без `--script` и не меняет состояние наблюдателем; его область —
прибытие, ходьба, осмотр указателя, журнал/сумка, запись/загрузка и изоляция тестового режима.
Временный `override.cfg` наблюдателя после проверки удалён.

Основные проверки можно повторить из корня репозитория:

```sh
godot --headless --editor --path HutorReborn --import --quit
godot --headless --path HutorReborn --script res://tests/verify_chapter_rules_70.gd
godot --headless --path HutorReborn --script res://tests/verify_chapter_flow_70.gd
godot --headless --path HutorReborn --script res://tests/verify_chapter_branches_70.gd
python -B HutorReborn/tests/verify_chapter_sources_70.py
```

Сюжетные фикстуры используют тестовые слоты. Для нативного Linux/X11 прогона служит
`tools/run_chapter_native_70.py --output <новый-каталог> --record`; нужны ffmpeg и libXtst.
Он отказывается перезаписывать существующий `override.cfg`. Игра не требует Python или сторонних дополнений.

## Что остаётся проверить вручную на Windows

1. Пройти главу без тестовых перемещений: удобство дороги к трактиру, поиска NPC по времени,
   всех дворов/маршрутов, западного обхода, находок и входа в заброшенный дом.
2. Оценить текст, темп расследования, мотивацию решений и ясность текущих целей; отдельно пройти
   оплату/отработку и варианты топора/финального расследования.
3. Проверить на целевом экране ночную читаемость, мебель/перекрытия, фигуру в финале, туман, громкость и масштабирование окна.
4. Проверить F5/F9, контрольную точку, доступность каталога сохранений Windows и восстановление после перезапуска приложения.
5. Проверить редкие живые события при обычном ходе часов и сопровождение при намеренном перекрытии проходов Гансом.
6. Экспорт Windows не выполнялся. Для будущего export preset нужны существующие нересурсные JSON-конфигурации проекта (`*.json`).

Ограничения представления: волки используют временную графику арены 6.1 без полноценной покадровой ходьбы;
голос из леса показан субтитром без актёрской озвучки. Сохраняется занятие NPC, но не точный кадр его жеста.
Дневные работы жителей продолжают использовать существующий закадровый район; сюжетная старая вырубка — отдельное место.
В виртуальном Linux-драйвере есть предупреждение об управлении V-Sync; оно не является ошибкой GDScript.

Основные игровые цепочки реализованы; перечисленные ограничения не заменяются фиктивными «готовыми» анимациями
или заявлением о ручном Windows-прохождении. PR подготовлен отдельно и автоматически не объединяется.
