# hutor-reborn
Atmospheric Slavic dark fantasy RPG built with Godot 4.6

Open `HutorReborn/project.godot` in Godot 4.6 and press F5 to play «Кривая Сосна». Stage 2 documentation: `HutorReborn/docs/KRIVAYA_SOSNA.md`.

The starting area is now 2624 × 2176 px (2.003× its previous area), with expanded yards and forest trails and pixel-preserving seamless terrain. Current documentation and validation: [KRIVAYA_SOSNA_EXPANDED.md](HutorReborn/docs/KRIVAYA_SOSNA_EXPANDED.md).
