# Hans Reborn Idle v1

Новая экспериментальная анимация из **12 различных RGBA PNG** от одного нового общего мастера. **1280×1280**, pivot **(706,1185)**, 4 FPS, цикл **3 с**. Не подключена к игре; утверждение внешности и движения остаётся ручным.

Фон не удалялся по RGB. Сырой генераторский RGBA имеет слегка неполное покрытие и внешний alpha-шум, поэтому отдельно сохранена маска **по поставленному alpha**, проверенная до анимации. Её геометрия не зависит от цвета: тёмные участки не удаляются. Все 727 совершенно чёрных текселей внутри исходного покрытия остаются непрозрачными. В исходные alpha=0 ничего не дорисовывается. Итоговые кадры имеют alpha только 0/255, один связный силуэт и **ноль замкнутых прозрачных дыр в каждом**.

Никаких двенадцати независимых отрисовок или повторного использования старых кадров под новыми именами нет. Текстура груди/плеч и свободная часть плаща движутся локально от общего 2D-рига; голова, руки, меч, рюкзак и стопы закреплены. Весь спрайт не масштабируется для дыхания. Первый/последний кадры — соседние фазы замкнутого цикла, без повторённого конечного кадра.

Автоматические проверки целостности не доказывают художественное качество или точное совпадение лица с каноном. Посмотрите MP4 и сравнения перед утверждением. Новый мастер — новая отрисовка по эталону; мелкие детали внешности и естественность движения требуют оценки пользователя. Windows и аппаратный GPU здесь не проверялись. **Hans Idle v2, другие анимации, волк, леший, UI, механики и арена остаются без изменений.**

## Воспроизведение

Готовые PNG находятся вне проекта. Не переносите их в игровые папки до утверждения.

```sh
HANS_REBORN_DIR=/absolute/path/to/deliverables/hans-reborn-idle-v1 \
  Godot --headless --path HutorReborn --script /absolute/path/to/render_idle.gd
python deliverables/hans-reborn-idle-v1/verify_idle.py
```

В ограниченной Linux-среде задайте `XDG_DATA_HOME`, `XDG_CONFIG_HOME`, `XDG_CACHE_HOME` в отдельную записываемую временную папку. Это не требуется для обычного пользовательского профиля с правом записи. Генератор читает `working/color_source.png` и `working/rig.json`, пишет только новые материалы этой папки; игровые ресурсы не трогает. Сырой источник зафиксирован: повторное художественное генерирование может дать другую внешность, поэтому для воспроизведения используются сохранённые PNG/маска.

Для интерактивного внешнего просмотра запустите `preview.gd` через тот же `--path HutorReborn --script ...` в графическом режиме с `HANS_REBORN_DIR`; без `HANS_REBORN_CAPTURE` просмотр остаётся интерактивным. С этой переменной, указывающей на новую пустую временную папку, выполняются покадровые захваты, четыре проверки циклов и временный показ в существующей арене. Файлы SpriteFrames и сцены не сохраняются.

Для MP4 одновременно запустите `record_godot.py --capture-dir ... --output .../IDLE_COMPARISON.mp4 --display ...`; для сборки технических атласов — `build_evidence.py --captures ...`. Python использует Pillow, numpy, scipy; запись — FFmpeg. Видео сжато 4:2:0: точную прозрачность/цвет проверяйте по PNG, не по MP4. Временные профили, кеши и отклонённые уменьшенные кадры в PR не включены.

PR предназначен для просмотра и художественного утверждения. Автоматическое объединение и интеграция в игру не выполняются.
