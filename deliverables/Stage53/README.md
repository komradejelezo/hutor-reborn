# Материалы визуального аудита 5.3.1

Основной документ: [VISUAL_AUDIT_5_3.md](../../VISUAL_AUDIT_5_3.md).

- `screenshots/native-*` — захват штатного игрового окна во время прохода WASD/E, без телепортации и установки времени.
- `screenshots/diagnostic-*` — полный обзор сохранённых сцен с диагностической камерой. Мировая сцена и эффекты загружены в Godot; позиция камеры отличается от игрового следования. Это не тест управления.
- `videos/native-*` — реальные оконные записи, 20 FPS, без звука. Частота записи не доказывает такой же FPS рендера. `native-interior-woodcutter.mp4` показывает короткий эпизод до упора маршрута наблюдения в стул; продолжение наблюдения вынесено в отдельный ролик. Обход стула и возврат к выходу записаны в журнале действий.
- `videos/diagnostic-resource-preview.mp4` — фактические SpriteFrames, увеличение 2× Nearest, 0–18 с: Walk/Idle четырёх направлений; 18–36 с: рабочие клипы NPC. Ганс после 18 с не используется для сравнения. Нет навигации и игровых коллизий; фон и опорные линии принадлежат стенду.
- `videos/diagnostic-environment-effects.mp4` — около 9 с живых эффектов у дома старосты с установленной диагностической камерой. Свет, эмиттеры и шейдеры не перенастраивались.
- `npc-temporal-strips.png` — три последовательных отсчёта Walk каждого ракурса из ролика ресурсов; каждый персонаж показан при увеличении 2×.
- `hans-motion.png` — вырезки игрового ролика через 0,25 с, без увеличения, с временными отметками.
- `alpha-detail.png` и `source-tables.png` — вырезки существующих ресурсов, увеличение 4× Nearest; новые рисунки не создавались.
- `interiors-contact.png` — уменьшенные вдвое Nearest диагностические виды шести помещений. Для мелких деталей открыть отдельные полные PNG.
- `portraits-contact.png` — девять существующих нейтральных портретов в исходном разрешении; не тест веток диалогов.
- `diagnostic-village-full.webp` — lossless-кодирование полного PNG захвата, 2976 × 2560; декодированный RGB побайтово совпадает с PNG. Проверка указана в `evidence/provenance.json`.

`evidence/native-actions.jsonl` содержит состояния на снимках и реальные игровые действия. Координаты и instance ID — диагностика этого запуска, не сохранения игры. `visible-coverage.json` показывает экранную видимость и клипы по чтению наблюдателя: это не гарантия ручного просмотра каждого кадра. `animation-inventory.json` — данные загруженных ресурсов, без их изменения. Полный исходный поток телеметрии и временные инструменты остались вне репозитория.

Логи Godot не содержат зарегистрированных ошибок GDScript/ресурсов в проверенных запусках. Предупреждение V-Sync связано с программным графическим драйвером. В логах диагностических записей сохранено сообщение X11grab о shared-memory захвате; декодируемость опубликованных MP4 проверена отдельно. Его нельзя приписывать игровому коду или умалчивать об ограничениях записи.

`evidence/baseline-sha256.json` фиксирует хеши всех 1516 файлов исходной ревизии; `provenance.json` — результат повторного сравнения и параметры проверки; `artifacts-sha256.json` — хеши остальных материалов этого каталога. Этот каталог не содержит игровых сцен, скриптов или заменяющих ассетов.
