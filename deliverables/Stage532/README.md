# Проверка визуальных исправлений 5.3.2

Основной документ: [VISUAL_FIXES_5_3_2.md](../../VISUAL_FIXES_5_3_2.md).

`screenshots/*-before-after.png` — сравнения со снимками PR #20. Шесть комнат используют те же диагностические камеры и размеры окна. Наружные виды «до» вырезаны без масштабирования из прежнего lossless полного кадра карты; регион мира совпадает. Различия времени/положений NPC возможны и не используются для сравнения планировки. Новые графические ресурсы в этих монтажах не создавались.

`npc-alpha-before-after.png` — фиксированный одинаковый вырез существующих кадров, увеличение 4× Nearest на контрастном фоне. Опоры тел не выравнивались заново. `child-run-temporal.png` — последовательность кадров из фрагмента с 16-й секунды игрового ролика, без увеличения. Метки времени относительны фрагменту.

`videos/` — штатная главная сцена, настоящие оконные WASD/E, 20 FPS, без аудиодорожки. Перед наблюдением мальчика использована обычная F7 с последующим возвратом к ×1. Входы/выходы и наблюдение бега подтверждаются read-only журналом `checks/native-actions.jsonl`. Временный observer override не входит в проект.

`checks/` содержит окончательные журналы проверок после исправлений. Они различают реальное управление, автоматические Godot-фикстуры и анализ исходников. `provenance.json` фиксирует базовую ревизию, контроль исходников и декодируемость видеозаписей. Производительность аппаратного GPU/60 FPS не заявляется. Исходные звуковые записи сохранены; автоматический аудиотест проверяет PCM, графический запуск выполнен с Dummy audio.
