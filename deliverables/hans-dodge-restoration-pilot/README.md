Приняты **410** новых редакторских пикселей: 235 восстанавливают покрытие; 175 заменяют прежнее чёрное покрытие, где архивный исходник не содержит цвета. Это новая пробная художественная фактура, а не найденные оригинальные цвета. Все здоровые видимые RGB и защищённые просветы/края сохранены попиксельно. Отсутствие новых прозрачных пикселей дополнительно проверено топологией: новых замкнутых отверстий тоже нет.

В прежних подтверждённых ядрах PR №43 остаётся **104** пикселей (06: 30, 07: 42, 08: 32). Это только часть оставшихся повреждений. Крупные просветы плаща пока нельзя достоверно классифицировать/восстановить этим инструментом без ручной покадровой работы. Оранжевые маски — подозрения, не разрешение заливать воздух. Полное художественное качество и отсутствие мерцания всех исходных разрывов не подтверждены.

## Проверка и воспроизведение

Godot 4.6.2 Linux/X11/llvmpipe: **76 проверок, 0 ошибок**. Декодированный MP4 содержит все пять поз 05–09 на белом и розовом. PNG — основной материал для оценки цвета/alpha; стандартное видео 4:2:0 меняет розовые края. Windows и аппаратный GPU остаются для ручной проверки.

В метаданных записи `late_frames_over_25ms` означает отставание от накопленного таймера, включая запуск энкодера; это не число пропущенных игровых кадров. Программный захват не доказывает идеальный frame pacing на аппаратном GPU. Покрытие записи всеми пятью позами проверено отдельно после декодирования.

`patches/` содержит только принятые текстурные пиксели редакторского прохода. Целые редакторские исследования не использованы: они меняли контекст. Для воспроизведения результата достаточно `python deliverables/hans-dodge-restoration-pilot/rebuild_pilot.py`; он проверяет SHA исходников и записывает только `restored/`. Никакой генерации ткани/заливки по алгоритму в этом скрипте нет.

`verify_pilot.py` независимо проверяет сохранность исходников, геометрии, пикселей и alpha. `capture_pilot.gd` — внешний диагностический драйвер прежних Lab/арены: для просмотра дублирует SpriteFrames в памяти и подставляет ImageTexture из этой папки. `.tres` и игровые сцены не пишет. Переменные: `PILOT_DIRECTORY` — абсолютный путь сюда; `PILOT_CAPTURE_OUT` — новая пустая временная папка. Запуск Godot: `--path HutorReborn --script /абсолютный/путь/capture_pilot.gd` в графическом режиме. Для записи одновременно запустить `record_pilot.py --capture-dir ... --output .../DODGE_05_09_COMPARISON.mp4 --display ...`.

`build_evidence.py --captures ...` собирает диагностические композиции из существующих/замороженных PNG, `verify_video.py --captures ...` проверяет декодированное видео по настоящим кадрам Godot. Python-зависимости: Pillow, numpy, scipy; для записи — FFmpeg. Временные рабочие профили/кеши не включены в PR. Пилот не подключён к игре, PR не объединяется автоматически.
