# Этап 6.1 — экспериментальная пошаговая боевая система

Основа: `main` / `f5221a2` после PR #33. Ветка: `codex/stage61-combat-prototype`.
Проверено в Godot **4.6.3**, Linux, Compatibility / Mesa llvmpipe.

## Как открыть и управлять

1. Открыть `HutorReborn/project.godot` в Godot 4.6.x и запустить проект (F5).
2. В меню выбрать **«Испытание боем»**, затем один из шести сценариев.
3. Выбрать действие внизу и щёлкнуть по подсвеченной цели. Защита и отступление выполняются сразу. Игрок управляет всеми союзниками; враги действуют автоматически.
4. Золотая рамка и строка «Ход» обозначают активного бойца, зелёные рамки — доступные цели. Наведение показывает характеристики и причину недоступности цели.
5. «Заново» восстанавливает исходное состояние текущего испытания; «Сценарии» позволяет выбрать другое. «Анимации ×3» ускоряет только показ действий. Esc открывает выбор сценария, повторный Esc возвращает в меню.

Можно также открыть `scenes/combat/CombatTestArena.tscn` непосредственно и нажать F6.

До этого этапа проект запускал деревню напрямую: отдельного главного меню в исходной версии не было. Добавлено небольшое стартовое меню. **«Начать путь» открывает прежнюю сцену деревни.** Единственное изменение существующего файла — значение `run/main_scene` в `project.godot`. Выход из деревни в новое меню на этом этапе не добавлялся.

| Лесная засада | Ганс / 2 волка | Выбор противника; 2 настойки; отступление 40% |
| Плечом к плечу | Ганс, дровосек / тварь, дух | Дух в защищённом заднем ряду; 2 настойки; отступление 55% |
| Последняя настойка | Ганс, травница / тварь | 1 общая настойка, 2 лечения травницы; отступление 55% |
| Цена предательства | Ганс, наёмник / волк, дух | Живой наёмник один раз переходит к врагам в начале 3-го раунда, сохраняет HP, меняет позицию и произносит реплику в журнале; отступление 50% |
| Шёпот леса | Ганс / тварь | По одному применению корней и покровительства ворона; 2 настойки; отступление 55% |

## Правила прототипа

- На каждой стороне два ряда по два фиксированных места. Максимум три союзника, включая Ганса. Движения по клеткам нет. При предательстве наёмник занимает свободное место противоположной стороны.
- В каждом раунде живые бойцы ходят по убыванию инициативы. При равенстве сохраняется порядок из конфигурации. Погибшие пропускаются, предательство не создаёт дополнительного хода.
- Живой передний ряд закрывает задний от ближней атаки. Боец ближнего боя в собственном тылу также не атакует через своих передних бойцов. Дальняя атака травницы/духа и помощь проходят через ряды. При отсутствии целей остаются защита и другие допустимые действия.
- Попадание определяется отдельным броском точности; урон имеет разброс ±15%, затем вычитается броня, минимум 1. Защита делит полученный урон пополам с округлением вверх и действует до начала следующего собственного хода.
- Общая настойка восстанавливает до 30 HP живому союзнику; лечение травницы — до 32 HP. Здоровье не превышает максимум. Нет воскрешения. Недопустимая цель не тратит ход или запас.
- Неудачное отступление тратит ход: далее действует обычная очередь. Успешное завершает испытание без изменений основной игры.
- Корни пропускают ровно один следующий ход выбранного врага. Ворон снижает точность следующих **двух попыток** атаковать Ганса на 25 процентных пунктов, включая промахи. Это помощь леса, а не заклинания Ганса.
- Шёпот духа снижает урон жертвы на 5 на два её действия. У духа есть перезарядка. Волк быстр и предпочитает раненых, тварь медленнее и чаще защищается, наёмник после предательства предпочитает атаковать Ганса. Все используют общий API допустимых целей.
- Победа, поражение и успешное отступление останавливают действия и открывают итоговый экран. Повторный щелчок во время действия игнорируется. Перезапуск/смена сценария/возврат отменяют ожидающие действия ИИ и эффекты старого боя.

## Архитектура и ресурсы

| Файлы | Назначение |
|---|---|
| `data/combat/prototype.json` | Параметры 7 типов бойцов, 6 составов, расходники, эффекты, шанс отступления |
| `scripts/combat/combat_unit.gd`, `combat_catalog.gd`, `combat_battle.gd` | Независимые значения бойцов, загрузка конфигурации, синхронные правила и локальный RNG |
| `scripts/combat/combat_ai.gd` | Простой выбор допустимых действий врагами |
| `scenes/combat/CombatTestArena.tscn`, `scripts/combat/combat_arena.gd` | Экран арены, журнал, выбор действия, отменяемый показ ходов и результаты |
| `scenes/combat/CombatantView.tscn`, `scripts/combat/ui/*` | Карточка бойца, тема, эффекты выбора/удара/попадания/промаха/смерти/корней |
| `scenes/menu/MainMenu.tscn`, `scripts/menu/main_menu.gd` | Новое небольшое меню и два независимых пути запуска |
| `assets/combat/stage61/*` | Новый временный фон и 4 отдельные позы: волк, тварь, дух, наёмник |
| `tests/verify_combat*61*`, `tools/*combat*61*` | Проверки правил, интерфейса, исходников и нативного управления мышью |
| `tools/prepare_combat_61.py` | Воспроизводимая техническая подготовка новых поз/фона, manifest с SHA-256 |

Ганс использует существующие `assets/characters/hans_frames.tres`, дровосек — `assets/npc/woodcutter542/game/frames.tres` и палитру 5.4.3, травница — `assets/npc/herbalist5410/game/frames.tres` и её палитру. Использованы исходные шрифты DejaVu. Утверждённые изображения и SpriteFrames не изменены. Новые изображения созданы для этого прототипа; материалы Disciples II не использовались.

У новых противников и наёмника **по одной временной позе**, а не полноценные покадровые боевые наборы. Атака показана коротким выпадом, попадание — вспышкой/сдвигом и числом урона, смерть — затуханием. Существующие герои используют свои Idle-кадры. Нет подмены одинаковыми кадрами якобы готовой анимации. Все изображения отображаются с Nearest, прозрачные пиксели новых поз очищены; исходники хранятся в `source/` под `.gdignore` и отслеживаются Git.

Боевые значения создаются заново при каждом запуске и не ссылаются на экземпляры жителей или Ганса в деревне. Нет боевого autoload, записи сохранений, опыта, денег, постоянных характеристик или изменений NPC. Меню и арена вызывают существующий идемпотентный настройщик ввода: это необходимо, поскольку прежний запуск настраивал действия только при открытии деревни. Сам настройщик и клавиши не менялись.

### Графический запуск и движение во времени

Обычный запуск проекта Godot 4.6.3 в Linux/X11; управление настоящими событиями мыши XTest, а не `Input.parse_input_event` или вызовами боевых методов. Временный наблюдатель только читает состояние; он не входит в `project.godot`, его `override.cfg` удалён после проверки.

Пройдены все шесть испытаний, защита/настойка/лечение, защищённый тыл, помощь леса, перезапуск во время анимации, предательство на 3-м раунде без дублирования очереди, победа, поражение, успешное отступление и возврат в меню. Исходы определял обычный боевой RNG. Проверка цветов/показа выполнялась по скриншотам и последовательным кадрам записи, а не по одному статичному изображению.

## Повторение проверок

Из `HutorReborn/`:

```sh
godot --headless --editor --import --quit
godot --headless --script res://tests/verify_combat_61.gd
godot --headless --script res://tests/verify_combat_ui_61.gd
python -B tests/verify_combat_sources_61.py
```

Для проверки исходников нужен Pillow; только для повторной подготовки уже включённой графики нужны также NumPy/SciPy. Игра работает без Python и сторонних расширений. Старый тест прямого запуска деревни не изменялся: теперь исходной сценой является меню, и этот новый контракт проверяет `verify_combat_ui_61.gd`.

Необязательный нативный прогон для Linux/X11 с ffmpeg/libXtst, при окне 960×540 и без других запущенных окон игры:

```sh
DISPLAY=:0 python -B tools/run_combat_native_61.py --output /tmp/hutor-combat-review --record
```

Каталог вывода должен быть новым; существующий `override.cfg` инструмент не перезаписывает. Наблюдатель подключается только на время теста. В среде без графического дисплея использовать headless-проверки.

## Ограничения и ручная проверка Windows

- Новые боевые образы временные: полноценные покадровые атаки/смерть, звук боя, бег, сложные эффекты и окончательный художественный набор не входят в этот эксперимент. Корни имеют простой эффект линиями, ворон обозначен сообщением и статусом.
- Проверено окно 960×540 на Linux; на Windows нужно вручную оценить удобство выбора целей, читаемость на своём экране, целочисленное масштабирование при изменении окна и плавность обычной/ускоренной анимации.
- Повторить все шесть испытаний на Windows; особенно удержание/быстрые клики, перезапуск и выход во время ИИ, предательство, корни/ворон и возврат через меню к основной деревне. После этого проверить обычный разговор и вход в дом.
- Экспорт Windows не выполнялся. При подготовке export preset необходимо включить конфигурацию `data/combat/prototype.json` в экспорт нересурсных файлов (`*.json`) и проверить готовую сборку.
- Это баланс для оценки механики: опыт, добыча, постоянные спутники, сохранение боя, подключение к миру и сюжетным событиям намеренно отсутствуют. Никаких последствий для прогресса основной игры не записывается.
