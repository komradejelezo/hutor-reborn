HUTOR REBORN — Ганс, пробный комплект боевых анимаций v1

СОДЕРЖИМОЕ
idle/idle_01..12.png, idle/idle_strip.png — спокойная стойка
 dodge/dodge_01..12.png, dodge/dodge_strip.png — уход корпусом вниз (уклонение)
idle_pingpong_preview.gif, dodge_pingpong_preview.gif — превью
animation_manifest.json — точные размеры, порядок кадров, тайминги

ВАЖНО
Это ПРОТОТИПЫ, не финальные художественно вычищенные ассеты. Изображения извлечены из предыдущих анимаций. Чёрный фон удалён по порогу яркости автоматически: возможны чёрные каймы, полупрозрачность тёмной одежды, рябь и изменения деталей. Не обещать идеального качества. PNG подготовлены для проверки в Godot, не считать их окончательно утверждёнными.

ЗАДАЧА CODEX
1. Создать отдельную тестовую сцену/ресурс боевого Ганса в Godot 4.6.2. Не менять квесты, NPC, основные сцены и уже рабочую боёвку без необходимости.
2. Подключить PNG кадры из папок idle/ и dodge/ через AnimatedSprite2D/SpriteFrames (или текущую анимационную архитектуру). Важно: strip горизонтальный, не сетка; можно использовать отдельные PNG.
3. Реализовать ping-pong без дублирования крайних кадров: порядок см. manifest. Idle — ~115 мс/кадр, Dodge — ~52 мс/кадр, как стартовые настройки с возможностью настройки в инспекторе.
4. Выровнять опорную точку стоп, масштаб и положение между кадрами, исключить дрожание из-за смещения спрайтов. Не растягивать весь спрайт программно.
5. Idle играет непрерывно, Dodge вызывается тестовой кнопкой и затем возвращает Idle. Не вводить игровую неуязвимость, если она не предусмотрена текущими правилами боя.
6. Добавить простую тестовую панель: Idle / Dodge, скорость анимации, переключение фона тёмный/светлый для проверки прозрачности.
7. Прогнать проверки Godot, перечислить оставшиеся графические артефакты и что требует ручной дорисовки. Не выдавать автоматическую очистку фона за художественную подготовку.
8. Сделать отдельный PR; не объединять автоматически.

Дальнейшая задача (не в этом PR): ручная покадровая очистка, согласование фактуры и плаща, уточнение таймингов после визуальной проверки.
