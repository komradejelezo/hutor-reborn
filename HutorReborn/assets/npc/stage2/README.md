# Ресурсы NPC — этап 2

Оригинальные PNG импортированы без изменения пикселей и альфа-канала. Папка `Npc/` содержит семь RGB-листов с портретами, подписями и референсами. Остальные папки содержат готовые RGBA-листы персонажей с ячейками шириной 793 px; их оригинальные названия сохранены.

`Ганс/` — альтернативный образ из архива, не замена главному герою. Текущий Ганс продолжает использовать `assets/characters/hans_frames.tres`; совпадающие изображения из `Шаги/` повторно не копировались.

Сцены NPC, диалоги, расписания и поведение на этом этапе не создавались. Каталог размеров и SHA-256: `assets/stage2_catalog.json`. Описание использования — `docs/STAGE2_ASSETS.md`.
